1. **isbn**: Simples — É um valor atômico, indivisível e único que funciona como identificador do livro.
2. **endereco_editora**: Composto — Pode ser logicamente subdividido em partes menores (rua, número, bairro, CEP).
3. **telefones_editora**: Multivalorado — Uma mesma editora pode possuir diversos números de telefone simultaneamente.
4. **idade_do_acervo**: Derivado — Não é armazenado no banco, pois muda todos os dias; é calculado matematicamente a partir da diferença entre a data atual e a data de aquisição.
5. **titulo**: Simples — É um valor textual único e indivisível (o nome da obra).
6. **nome_autor**: Simples — Embora pudesse ser composto (nome e sobrenome), no contexto geral da biblioteca, atua como uma string simples de identificação textual.
7. **data_aquisicao**: Simples — É um valor temporal fechado, único para cada registro.
8. **qtd_exemplares**: Derivado — Não se digita esse número em uma tabela; ele é obtido dinamicamente contando (COUNT) quantos registros de exemplares daquela obra existem no sistema no momento da consulta.
